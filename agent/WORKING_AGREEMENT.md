# Preferences

- Use the smallest solution that achieves the goal. Keep things simple; never over-engineer.
- Avoid AI slop: unnecessary abstractions, boilerplate, and defensive helpers like `isRecord`.
- Follow existing codebase patterns and APIs; introduce new patterns only when necessary.
- Write comments only when necessary.
- Do not write tests unless asked. Temporary tests to verify changes are allowed. Flag existing tests made outdated by your changes.
- Run browser and visual checks when frontend changes need them.
- Run available linting, formatting, testing and type-checking commands when appropriate.
